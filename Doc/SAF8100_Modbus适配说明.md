# SAF8100（8100）通过 Modbus 接入说明

> 参考工程：`8100_OWI_Test_V1.0.0_251010`（SAF8100 官方 OWI 测试例程，STM32F103 / 72MHz）
> 目标工程：`WF100E_DEMO`（PY32F002B / 24MHz，Modbus RTU 从机，2×4 = 8 通道治具）
> 编写日期：2026-10-26

---

## 0. 先说结论：参考 demo 里没有 Modbus

这一点必须先讲清楚，否则会找错方向。

`8100_OWI_Test` 工程里**没有任何 Modbus 代码**：

| 能力 | 参考 demo 的实现方式 |
| --- | --- |
| 与 8100 通信 | 自研 OWI 单线协议（GPIO + TIM6/TIM7 + EXTI） |
| 与上位机通信 | **USART1 的 `printf` 打印日志**，单向输出 |
| 测试触发 | 上电后 `main()` 里自动跑一次 `hal_saf8100_example()` |
| 参数下发 | 无，全部硬编码在 C 代码里 |

所以"明确其使用的 Modbus 通信方式、寄存器地址"这件事，准确表述是：

- **OWI 侧**有明确的帧格式和寄存器地址表（来自 `owi.c` / `hal_saf8100_reg.h`），这部分完整沿用到本工程；
- **Modbus 侧**是**本次新设计**的，载体是 `WF100E_DEMO` 已有的 FreeModbus RTU 从机（从站地址 1，115200 8N1，保持寄存器 40001+ 下发命令，输入寄存器 30001+ 回读结果）。

## 1. OWI 物理层与帧格式

### 1.1 电气与时序

官方例程配置：`owiSetTxPhysics(32000, 32, 50, 75, 25)`

| 参数 | 值 | 含义 |
| --- | --- | --- |
| 位速率 | 32000 Hz | 位周期 31.25us |
| 停止位 | 32us | 附加在高电平之后 |
| 起始位占空比 | 50% | 低 15.6us / 高 15.6us |
| 逻辑 1 占空比 | 75% | **低 7.8us / 高 23.4us** |
| 逻辑 0 占空比 | 25% | **低 23.4us / 高 7.8us** |

本工程用 TIM1 的 1MHz 计数实现，取整为：位周期 31us、起始位低 15us、逻辑 1 低 8us、逻辑 0 低 23us、停止位附加 32us。

### 1.2 帧结构

```
[起始位] [D7] [D6] [D5] [D4] [D3] [D2] [D1] [D0] [P] [停止位]
  50%     ← 8 位数据，MSB 先发 →       偶校验  +32us
```

- 校验位：8 位数据的**偶校验**（逐位异或）。
- 应答：从机返回的首字节固定为 `0x55`，表示 ACK。

### 1.3 命令集

| 功能 | 发送帧（十六进制） | 应答帧 | 说明 |
| --- | --- | --- | --- |
| 登录 | `F3 A0` | `55` | 登录后才能读写寄存器 |
| 读寄存器 | `F4 <addr>` | `55 <data>` | 单字节读 |
| 写寄存器 | `<addr> <data>` | `55` | **无命令前缀**，地址直接作为首字节 |
| 读温度 | `F8 00` | `55 <TH> <TL>` | 16 位温度原始码 |

> 注意：写寄存器与读寄存器的帧格式**不对称**——读要先发 `0xF4`，写则直接发地址。

### 1.4 上电与登录时序（官方要求）

```
VDD 断电 → 等 100ms → VDD 上电 → 等 20ms → 发 F3 A0 → 期望回 0x55
```

本工程封装为 `saf8100_login()`。

## 2. SAF8100 寄存器定义

地址为 8 位寄存器地址，`owiReadRegister16(addr)` 表示先读 `addr`（高字节）再读 `addr+1`（低字节）拼成 16 位。

### 2.1 EFUSE / OTP 控制

| 地址 | 名称 | 位域 | 含义 |
| --- | --- | --- | --- |
| 0x02 | EFUSE_ADDR | [7:0] | EFUSE 读写地址 |
| 0x03 | EFUSE_WDAT | [7:0] | EFUSE 写数据 |
| 0x04 | EFUSE_CMD | bit0 `EFUSE_WR` | 写操作（W1C） |
| | | bit1 `EFUSE_RD` | 读操作（W1C） |
| | | bit7 `EFUSE_BURW` | 突发写使能 |
| 0x05 | EFUSE_RDATA | [7:0] | EFUSE 读数据 |

**烧写动作**：向 0x04 写 `0x81`（`EFUSE_WR=1` + `EFUSE_BURW=1`），保持 50ms，即把 `0x44~0xB5` 的寄存器内容固化进 OTP。**每颗芯片只能烧一次**。

### 2.2 实时工作寄存器

| 地址 | 名称 | 宽度 | 含义 |
| --- | --- | --- | --- |
| 0x06/0x07 | ACT_TH / ACT_TL | 16bit | 当前温度原始码 |
| 0x08/0x09 | ACT_GDH / ACT_GDL | 6+8 = **14bit** | 增益 DAC 当前值 |
| 0x0A/0x0B | ACT_ZDH / ACT_ZDL | 6+8 = **14bit** | 零点 DAC 当前值 |

### 2.3 OWI 控制

| 地址 | 名称 | 含义 |
| --- | --- | --- |
| 0x20 | OWI_QUIT | 写任意值退出 OWI 模式，转 VOUT 输出 |
| 0x21/0x22 | OWI_RECNTH / L | 退出后重新进入 OWI 的延时计数（ms） |
| 0x23 | CHOP_CTRL | 斩波控制（PGA1/2/3、ADC），大部分位 reserved |

### 2.4 修调寄存器（出厂标定，一般只读）

| 地址 | 名称 | 含义 |
| --- | --- | --- |
| 0x3D | TC_TRIM | 温度修调 [6:0] |
| 0x3E | CC_TRIM | 电流修调 [6:0] |
| 0x3F | ABS_TRIM | 绝对精度修调 [5:0] + PNP_SEL |
| 0x40 | GBIAS_TRIM | 偏置修调 [4:0] + REFOUT_TRIM[2:0] |
| 0x41 | OSC_TRIM | 振荡器修调 [4:0] + REFOUT_TRIM[4:3] |
| 0x42 | PGA2_CMRR0 | PGA2 增益0 CMRR 修调 + OWI_FSRD |
| 0x43 | IDAC_TRIM | IDAC 修调 [4:0] |

### 2.5 功能配置寄存器（**OTP 烧写区，0x44~0xB5**）

| 地址 | 名称 | 位域 | 含义 |
| --- | --- | --- | --- |
| 0x44 | SYS_CTRL | bit0 `OWI_DIS` | 禁止 OWI 通信 |
| | | bit1 `IDAC_EN` | 0=电压驱动 1=电流驱动 |
| | | bit2 `R_MODE` | 0=普通 1=比例式 |
| | | bit3 `SPIN_EN` | 旋转检测使能 |
| | | bit4 `SPIN_TYPE` | 0=4 相 1=2 相 |
| | | bit5 `SWAP` | 信号极性反转 |
| | | bit6 `VOCD_EN` | 过流保护 |
| | | bit7 `TBG_EN` | 背栅驱动 |
| 0x45 | PGA_GAIN | [7:5] `G1` | 第一级增益 ×1~×32（8 档） |
| | | [4:2] `G3` | 第三级增益 ×1~×9（8 档） |
| | | [1:0] `G2` | 第二级增益 ×1/×2/×4/×6.5 |
| 0x47 | LUT_SEL | bit0 `FIX_CAL_EN` | 固定校准模式使能 |
| | | bit1 `LUT_CAL_EN` | LUT 校准使能 |
| | | bit2 `DAC_HP` | DAC 高功耗模式 |
| | | [7:3] `LOAD_LUT` | LUT 加载选择 |
| 0x48 | PGA_CTRL | [1:0] `VCM_SEL` | 0=1.5V 1=0.5V 2=1.65V 3=2.5V |
| | | [3:2] `SPIN_CLKS` | 旋转时钟 1M/2M/0.5M/0.25M |
| | | bit4/5 `CHOP_EN1/2` | PGA1/PGA2 斩波使能 |
| | | bit6 `REF_GAIN` | 0=基准 ×1 1=×1.6384 |
| | | bit7 `VREF_SEL` | 0=内部 2.5V 1=VDD/2.0 |
| 0x4A | COEFF_C | 8bit | 补偿系数 C |
| 0x4B | ADC_CTRL | [2:0] `AVG_NUM` | 平均次数 128/64/32/16/8/4/2/1 |
| | | [4:3] `OSR` | 过采样率 512/256/128/64 |
| | | bit7 `SOT_EN` | 一阶/二阶插值选择 |
| 0x4C~0x5D | Tx / GDx / ZDx（x=0~2） | 6 字节×3 组 | 三个温度点的 T / 增益 DAC / 零点 DAC 系数 |
| 0xB2~0xB5 | COEFF_A / COEFF_B | 16bit 有符号 | 补偿系数 A、B |
| 0xB6~0xB9 | PGA1_OFFP / OFFN / PGA2_OFF / REFOUT_OFF | — | PGA 失调与温度修调 |
| 0xBA/0xBB | PGA2_CMRR1 / CMRR2 | — | PGA2 各级 CMRR 修调 |

> **OTP 烧写范围：寄存器 0x44 ~ 0xB5**（官方注释明确说明），也就是从上表的 `SYS_CTRL` 一直到 `COEFF_B` 低字节。

## 3. 参考 demo 的测试流程

`hal_saf8100_example()` 的实际执行顺序：

| 步 | 动作 | 对应代码 |
| --- | --- | --- |
| 1 | OWI 初始化（32kHz、GPIO 方向、VDD 断电） | `owiInit(32000)` |
| 2 | 断电 100ms → 上电 → 等 20ms → 登录 | `owiLogin()` |
| 3 | 读原始配置：0x08~0x0B、0x45、0x4B | `owiReadRegister()` ×6 |
| 4 | 写零点 DAC = 16383 | `hal_setActZD(16383)` |
| 5 | 写增益 DAC = 10000 | `hal_setActGD(10000)` |
| 6 | 写 VREF/VCOM：`VREF_SEL=0, REF_GAIN=1, VCM=2.5V` | `hal_setVrefVcom(0,1,VCM_SEL_2_5_V)` |
| 7 | 写采样率：`OSR=128, AVG_NUM=4` | `hal_setTemperSampRate(OSR_128, AVG_NUM_4)` |
| 8 | 写增益：`G1=4x, G3=4x, G2=4x` | `hal_setPGA(PGA_G1_4X, PGA_G3_4X, PGA_G2_4X)` |
| 9 | 回读 0x08~0x0B、0x45、0x4B 校验 | `owiReadRegister()` ×6 |
| 10 | 延时 200ms 后读温度并换算 | `hal_getActTemp()` |
| 11 | （注释掉）退出 OWI 转 VOUT 输出 | `hal_exit_owi_meas_vout(60000)` |
| 12 | （注释掉）断开上拉电阻 | `setVoutPullUp(0)` |

温度换算公式：

```
T(℃) = (temp_code - 32383.8) / 114.2
```

## 5. 本工程的 Modbus 实现

### 5.1 通信参数（沿用现有固件）

| 项 | 值 |
| --- | --- |
| 协议 | Modbus RTU 从机 |
| 从站地址 | 1 |
| 串口 | 115200 8N1 |
| 下发命令 | 写保持寄存器 `40001` 起 |
| 回读结果 | 读输入寄存器 `30001` 起 |

帧内布局（与现有产品命令一致）：

```
40001 = 5          命令大类（5 = 产品/测试类）
40002 = 具体命令码
40003... = 参数
```

### 5.2 新增的任务号（写入 `40003`，配合命令 `0x77`）

| 任务号 | 名称 | 流程 |
| --- | --- | --- |
| 5 | `TS_8100TEST` | 全流程：登录 → 读原始配置 → 写配置 → 回读校验 → 测温 |
| 6 | `TS_8100MEAS` | 快速测温（登录 + 读温度） |
| 7 | `TS_8100FUSE` | 全流程 + OTP 烧写 + 烧后回读校验 |

下发示例（扫描全部 8 通道）：

```
写 40001=5, 40002=0x77, 40003=5, 40004..40007=0
```

### 5.3 新增命令

| 命令码 | 名称 | 参数 | 返回 |
| --- | --- | --- | --- |
| `0x610` | 读 8100 测试数据 | `40003` = 起始通道号 | 每颗 8 个输入寄存器，见 5.4 |
| `0x780` | 写 8100 配置 | `40003`=act_gd，`40004`=act_zd，`40005`=pga_gain，`40006`=pga_ctrl，`40007`=adc_ctrl，`40008`=sys_ctrl，`40009`=lut_sel，`40010`=valid(1 生效) | `30001` = 1 表示已写入 |

### 5.4 `0x610` 数据布局（每颗芯片 8 个 16 位寄存器）

| 偏移 | 内容 | 拆分方式 |
| --- | --- | --- |
| +0 | `login` / `err` | 高字节 = 登录应答（0x55 正常），低字节 = 错误码 |
| +1 | `act_gd` | 0~0x3FFF（14bit 增益 DAC） |
| +2 | `act_zd` | 0~0x3FFF（14bit 零点 DAC） |
| +3 | `pga_gain` / `adc_ctrl` | 高字节 = 0x45，低字节 = 0x4B |
| +4 | `pga_ctrl` / `sys_ctrl` | 高字节 = 0x48，低字节 = 0x44 |
| +5 | `lut_sel` / `fuse_done` | 高字节 = 0x47，低字节 = 烧写完成标志 |
| +6 | `temp_code` | 温度原始码 |
| +7 | `temp_x100` | 温度 ×100（**有符号**，0x0DAC = 35.00℃） |

一次最多读 15 颗（120 个输入寄存器 ÷ 8），本机 8 通道，一次可全读。

错误码（低字节）：

| 值 | 含义 |
| --- | --- |
| 0x00 | 正常 |
| 0x01 | 登录失败（0x55 未收到） |
| 0x02 | OWI 通信失败（应答缺失或校验错） |
| 0x03 | 写后回读不一致 |
| 0x04 | OTP 烧写失败 |

### 5.5 配置寄存器取值换算

上位机只需下发**寄存器原始字节**，下面给出位域拼装公式（固件内已提供同名函数，便于查阅）：

```
0x45 PGA_GAIN  = (G1 << 5) | (G3 << 2) | G2
0x4B ADC_CTRL  = (OSR << 3) | AVG_NUM
0x48 PGA_CTRL  = (VREF_SEL << 7) | (REF_GAIN << 6) | VCM_SEL
```

上电默认值（与官方 demo 一致）：

| 项 | 值 | 寄存器字节 |
| --- | --- | --- |
| 零点 DAC | 16383 | 0x0A=0x3F, 0x0B=0xFF |
| 增益 DAC | 10000 | 0x08=0x27, 0x09=0x10 |
| VREF_SEL / REF_GAIN / VCM | 0 / 1 / 2.5V | 0x48 = 0x43 |
| OSR / AVG_NUM | 128 / 4 | 0x4B = 0x15 |
| G1 / G3 / G2 | 4x / 4x / 4x | 0x45 = 0x52 |

## 7. 与官方 demo 的差异（务必确认）

### 7.1 硬件引脚差异（最关键）

| 信号 | 官方 demo | 本治具（SOP100E） |
| --- | --- | --- |
| OWI 输出 | `OWI_OUT` = PA7（独立引脚） | `OUT1`=PA4 / `OUT2`=PA3（与输入共用一根线） |
| OWI 输入 | `OWI_IN` = PA6（独立引脚 + EXTI） | 同上，靠切换 GPIO 方向实现 |
| 上拉控制 | `CTRL_OWI_UP` = PB3（可断开上拉） | 无独立控制脚，依赖治具外部上拉 |
| VDD 控制 | `CTRL_VDD` = PB5，**低电平有效** | `VDD1~4`，**高电平有效** |
| VOUT 测量 | 独立 VOUT 网络 | 通过 ADC 读同一根线 |

**必须确认**：治具的 `OUT` 线是否同时接到 8100 的 `OWI_OUT` 与 `OWI_IN`（或芯片只有一个双向 OWI 引脚）。若芯片确实是两根独立线，本治具无法直接驱动，需要改板。

### 7.2 软件实现差异

| 项 | 官方 demo | 本工程 |
| --- | --- | --- |
| 发送 | TIM7 + 中断换 ARR 生成 PWM | TIM1 1MHz 计数 + 轮询延时 |
| 接收 | EXTI 边沿捕获 + TIM6 计数 | 轮询采样 + TIM1 计时 |
| 中断处理 | 独立 EXTI 中断 | 通信期间关闭 TIM14（Modbus T3.5）中断避免抖动 |
| 多通道 | 单通道 | 2×4 = 8 通道轮询 |

### 7.3 已知限制

1. **轮询式接收受中断抖动影响**：已通过关闭 TIM14 中断缓解，但 USART1 中断仍可能插入。若现场误码率高，建议改用 EXTI 捕获。
2. **时间精度**：位周期取整为 31us（理论 31.25us），误差 0.8%，在占空比判定容差（37.5%/87.5%）内。
3. **OTP 不可逆**：`TS_8100FUSE` 执行后芯片无法恢复，上线前务必先用空白片验证 `TS_8100TEST`。
4. **未做芯片型号识别**：无法区分插的是 8100 还是其他同封装芯片。

## 8. 验证步骤建议

1. 单通道接一颗已知正常的 8100，先跑 `TS_8100MEAS`（任务号 6），确认 `login = 0x55`、`temp_code` 合理；
2. 再跑 `TS_8100TEST`（任务号 5），检查 `act_gd ≈ 10000`、`act_zd ≈ 16383`、`temp_x100` 在室温范围内；
3. 用示波器抓 `OUT` 线，确认起始位占空比 50%、逻辑 1 低电平 8us / 逻辑 0 低电平 23us；
4. 上述全部通过后再启用 `TS_8100FUSE`，且先用废片验证烧写与回读。
